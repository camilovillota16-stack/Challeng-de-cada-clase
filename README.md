El índice enumera los ejercicios previstos. Una rama contiene una entrega únicamente cuando existe en GitHub y su README describe la implementación.

## Cómo revisar un ejercicio

En GitHub, abre el selector que muestra `main` y selecciona la rama del challenge. Allí encontrarás su código y las instrucciones para ejecutarlo.

En tu computador:

```bash
git clone https://github.com/camilovillota16-stack/Challeng-de-cada-clase.git
cd Challeng-de-cada-clase
git switch codex/challenge-03-listas
```

Después sigue el README de esa rama. Las ramas se crean desde `main` para conservar cada ejercicio de manera independiente.
